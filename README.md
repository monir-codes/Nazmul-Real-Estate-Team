# Nazmul Real Estate Team Website

A premium, full-stack real estate team website built with the MERN stack (React, Vite, Express, MongoDB) and Tailwind CSS v4.

## Features
- Premium, high-converting UI (Animations, Glassmorphism, Modern typography).
- Responsive layouts for Mobile and Desktop.
- Fully functional Admin Dashboard.
- Secure backend API with JWT authentication.
- Lead Generation & Contact Forms.
- Dynamic property listings grid and details.

## Setup Instructions
1. Install root dependencies: `npm install`
2. Configure `.env` in the backend directory.
3. Start the dev environment: `npm run dev`

Designed and built for Nazmul Real Estate Team.
